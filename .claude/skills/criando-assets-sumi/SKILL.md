# Criando assets no estilo sumi (Nagare)

## Visão geral
A IA de imagem gera **peças paradas e isoladas**; o código transforma em asset e o app anima. Nunca peça à IA a tela pronta, GIF, ou o estado ativo de um ícone.

## Fluxo
1. **Escrever o prompt** a partir dos blocos de `prompts.md` (estilo + tipo de peça). Sempre anexar a imagem-mestra `test-assets/estilo/imagem_mestra.jpeg`.
2. **Gerar no Gemini** (usuário, fora do Claude). Fundo **branco puro**, peças **separadas** com espaço entre elas. Salvar em `test-assets/estilo/<tipo>/` (fora do git).
3. **Olhar a imagem** (Read) antes de processar: leitura errada do tema (ex.: bordo que parece cannabis, frasco que parece mamadeira) → ajustar prompt e gerar de novo.
4. **Processar** com `python .claude/skills/criando-assets-sumi/scripts/processar.py <comando>` (`--help` em cada um). Requer `pip install pillow numpy scipy vtracer`.
5. **Conferir em tamanho real** sobre o papel (comando `revisar` para ícones; para o resto, uma prévia HTML) e mostrar ao usuário antes de levar ao app.

## Qual comando
| Peça gerada | Comando | Saída |
|---|---|---|
| Folha de ícones em grade (ou 1 ícone) | `icones --grade 3x3 --nomes a,b,...` (`1x1` p/ um) | SVG 24×24, `currentColor`, traço igualado |
| Pinceladas, ensō, bonsai em tinta | `tinta --prefixo pincel` (`--caixa` p/ recortar de uma folha-mestra) | PNG máscara cor `#2B1F17` (tingir via `mask-image`) |
| Folhas, pétalas (aguada translúcida) | `recorte --prefixo folha` | PNG transparente, cor "des-misturada" do branco |
| Vasos, objetos opacos | `recorte --solido --prefixo vaso` | PNG transparente com contorno cheio |
| Papel | `papel --saida papel.jpg` | textura repetível sem emenda |
| Pasta de SVGs | `revisar <pasta> --saida x.html` | página de conferência |

## Regras do sistema (decididas com o usuário)
- Paleta: papel `#F4F0E8`, tinta `#2B1F17`, barro `#493628`/`#AB886D`, vermelhão `#B23A2A` (só carimbo 流 e destaques). Cor nas ilustrações só na cerâmica (e folhas de outono).
- Ícones: grade 24, desenho ocupa 20/24, traço mínimo `--alvo 14` (de 240). Gerar **só a versão normal**. Ativo é feito em código: navegação = versão cheia (`-ativo`) + pincelada vermelha no lugar do nome; resto = "mancha de tinta" (círculo irregular `#2B1F17`, ícone claro).
- Utilitários (✓, X, setas, lixeira, lápis, busca) continuam Lucide.
- Movimento em código (partículas, recorte em camadas, máscara revelando traço). Vídeo (Veo) só em tela cheia, **9:16 vertical**.
- Carimbo 流 e qualquer texto/kanji: em código com fonte real, nunca pela IA.

## Erros comuns
| Erro | Correção |
|---|---|
| Peças encostadas na folha | `--juntar` menor, ou gerar de novo pedindo "very large gaps" |
| Ícones de um grupo mais finos que outros | já corrigido por `--alvo`; não baixar de 14 |
| Pedir versão ativa do ícone à IA | desnecessário; o código faz |
| Transparência gerada pela IA | pedir fundo branco puro; o script recorta |
| Vídeo horizontal / pincel aparecendo | pedir `vertical 9:16` e `no brush, no hand visible` |
| Grade com célula vazia | use `-` no lugar do nome em `--nomes` |
